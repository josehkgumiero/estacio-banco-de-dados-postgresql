# Projeto de Consultas básicas com SELECT nas Tabelas
O projeto está disponível em: [Projeto de Consultas básicas com SELECT nas Tabelas](./Basic_Query_SELECT_Tables.docx)

# Resumo
O documento apresenta um projeto prático de consultas básicas utilizando o comando SELECT no PostgreSQL, com o objetivo de consolidar os conceitos estudados anteriormente por meio da construção de um banco de dados completo e da execução de consultas SQL sobre suas tabelas. Inicialmente, o material propõe a criação de um banco de dados denominado EMPRESA, orientando o usuário a utilizar o ambiente PGAdmin 4 para estabelecer conexão com o servidor PostgreSQL, criar o banco de dados, carregar o script de criação das tabelas e validar sua estrutura. Essa abordagem prática permite que o estudante desenvolva familiaridade com o ambiente de desenvolvimento e compreenda todo o processo de implantação de uma base de dados antes da execução das consultas. Além disso, é apresentado um modelo de dados composto pelas entidades REGIÃO, DEPARTAMENTO, EMPREGADO e CLIENTE, ilustrando os relacionamentos existentes entre elas e demonstrando como a modelagem relacional organiza informações corporativas de maneira estruturada.

Na sequência, o documento apresenta o script completo de criação das tabelas utilizando comandos CREATE TABLE, definindo chaves primárias, chaves estrangeiras, restrições de integridade e tipos de dados adequados para cada atributo. São criadas as tabelas REGIAO, DEPARTAMENTO, EMPREGADO e CLIENTE, estabelecendo os relacionamentos entre departamentos e regiões, empregados e departamentos, empregados e gerentes, além da associação entre clientes e vendedores. Após a definição da estrutura do banco de dados, o material demonstra a inserção de registros utilizando comandos INSERT INTO, populando cada tabela com dados representativos de uma empresa fictícia. O processo é executado dentro de uma transação SQL, iniciada com BEGIN TRANSACTION e finalizada com COMMIT, reforçando boas práticas relacionadas à consistência e integridade das operações realizadas sobre o banco de dados.

Com a base de dados criada e populada, o documento concentra-se na execução de consultas utilizando o comando SELECT, explorando diferentes possibilidades de recuperação de informações. Inicialmente, é apresentada uma consulta que retorna todos os registros da tabela EMPREGADO por meio do comando SELECT *, permitindo visualizar integralmente os dados armazenados. Em seguida, são demonstrados exemplos de projeção de colunas específicas, selecionando apenas atributos como identificação, primeiro nome e sobrenome dos empregados. Esses exemplos evidenciam que o comando SELECT pode ser utilizado tanto para recuperar todas as informações de uma tabela quanto apenas os dados necessários para determinada análise, contribuindo para consultas mais objetivas e eficientes.

O material também apresenta exemplos envolvendo operações realizadas diretamente durante a consulta. Entre elas destaca-se o cálculo do salário anual, obtido pela multiplicação do salário mensal por doze, demonstrando a utilização de expressões aritméticas em instruções SQL. Além disso, é explorada a concatenação de colunas para formar o nome completo dos empregados utilizando o operador ||, seguida da aplicação da cláusula AS para atribuição de apelidos (aliases) às colunas resultantes. Esses recursos permitem produzir resultados mais intuitivos e adequados para apresentação em relatórios e aplicações, sem modificar a estrutura física das tabelas armazenadas no banco de dados.

Outro conjunto de exemplos aborda a utilização de funções de agregação para gerar indicadores estatísticos sobre os dados armazenados na tabela EMPREGADO. O documento demonstra como calcular a média salarial, a soma dos salários, o maior salário e o menor salário utilizando as funções AVG, SUM, MAX e MIN, evidenciando o papel dessas funções na produção de informações consolidadas para análises gerenciais. Em seguida, são apresentados exemplos de subconsultas, utilizadas para localizar o empregado com o maior identificador e o empregado com o menor identificador cadastrados no banco de dados. Esses exemplos ilustram como consultas podem ser combinadas para resolver problemas mais complexos, permitindo localizar registros específicos com base em resultados produzidos por outras consultas.

Ao longo do projeto, observa-se a integração de diversos conceitos fundamentais da linguagem SQL estudados anteriormente, incluindo criação de tabelas, inserção de dados, projeção de colunas, utilização de expressões aritméticas, concatenação de textos, aplicação de apelidos para colunas, funções de agregação e subconsultas. Dessa forma, o documento proporciona uma visão prática da construção e manipulação de bancos de dados relacionais no PostgreSQL, preparando o estudante para desenvolver consultas cada vez mais sofisticadas e para compreender o funcionamento de aplicações corporativas que utilizam bancos de dados como principal mecanismo de armazenamento e recuperação de informações.

# Conclusão

O projeto demonstra, de forma prática e integrada, como os principais conceitos da linguagem SQL podem ser aplicados na construção e manipulação de um banco de dados relacional utilizando o PostgreSQL. Ao conduzir o estudante desde a criação da estrutura do banco de dados até a execução de consultas envolvendo seleção de registros, projeção de colunas, cálculos, concatenação de informações, funções de agregação e subconsultas, o material evidencia que o domínio do comando SELECT constitui a base para praticamente todas as operações de consulta realizadas em sistemas gerenciadores de bancos de dados. Esse conhecimento representa uma competência essencial para profissionais que atuam nas áreas de desenvolvimento de software, administração de bancos de dados, Engenharia de Dados, Ciência de Dados, Business Intelligence e Analytics.

Outro aspecto importante apresentado pelo documento é a construção de um modelo de dados completo, composto por múltiplas tabelas relacionadas por meio de chaves primárias e estrangeiras. Essa abordagem aproxima o estudante de cenários encontrados em ambientes corporativos, nos quais diferentes entidades de negócio precisam ser organizadas de maneira consistente e integrada. A utilização de transações durante a carga inicial dos dados, associada às restrições de integridade definidas nas tabelas, reforça a importância de garantir confiabilidade, consistência e qualidade das informações armazenadas no banco de dados, princípios fundamentais para o desenvolvimento de aplicações robustas e escaláveis.

As consultas apresentadas demonstram que a linguagem SQL oferece recursos capazes de atender diferentes necessidades de recuperação e análise de dados. A possibilidade de selecionar colunas específicas, realizar cálculos diretamente durante a consulta, utilizar apelidos para melhorar a apresentação dos resultados, calcular indicadores estatísticos por meio de funções de agregação e empregar subconsultas para resolver problemas mais elaborados evidencia a flexibilidade e o poder expressivo da linguagem. Esses recursos permitem transformar dados armazenados em informações úteis para relatórios, sistemas corporativos, dashboards e processos de tomada de decisão, contribuindo diretamente para a geração de conhecimento e suporte às atividades organizacionais.

Em síntese, o projeto consolida diversos conceitos fundamentais estudados ao longo do módulo e estabelece uma base sólida para o aprendizado de tópicos mais avançados do PostgreSQL e da linguagem SQL, como cláusulas de filtragem (WHERE), ordenação (ORDER BY), agrupamentos (GROUP BY), junções entre tabelas (JOIN), visões (VIEW), funções analíticas e otimização de consultas. O domínio dessas técnicas permite ao profissional desenvolver consultas eficientes, produzir análises consistentes e construir soluções orientadas por dados capazes de atender às demandas de ambientes corporativos modernos. Dessa forma, o projeto representa um importante passo na formação de competências relacionadas ao gerenciamento, manipulação e análise de dados em bancos de dados relacionais, preparando o estudante para desafios técnicos mais complexos nas áreas de banco de dados e tecnologia da informação.
