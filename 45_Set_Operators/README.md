# Operadores de conjunto
O projeto está disponível em: [Operadores de conjunto](./Set_Operators.docx)

# Resumo
O material apresenta os operadores de conjunto da linguagem SQL no PostgreSQL, destacando sua utilização para combinar, comparar e diferenciar resultados provenientes de múltiplas consultas. Inicialmente, o documento explica que os operadores de conjunto permitem unir os resultados de diferentes instruções SELECT em um único conjunto de dados, desde que as consultas envolvidas possuam o mesmo número de colunas e tipos de dados compatíveis. São introduzidos os três principais operadores disponíveis no PostgreSQL: UNION, responsável pela união de conjuntos; INTERSECT, utilizado para identificar registros comuns entre consultas; e EXCEPT, empregado para retornar apenas os registros existentes na primeira consulta e ausentes na segunda. Esses operadores representam recursos importantes para integração e comparação de informações armazenadas em diferentes tabelas ou até mesmo em bancos de dados distintos.

Para demonstrar o funcionamento desses operadores, o documento propõe a criação das tabelas FUNCIONARIO, ALUNO e CLIENTE. Cada tabela representa um domínio de aplicação diferente, contendo informações como código, nome, CPF, sexo e, em alguns casos, data de nascimento e salário. Após a definição da estrutura das tabelas, são apresentados comandos de inserção de registros fictícios, simulando pessoas que podem aparecer simultaneamente em mais de uma tabela. O material ressalta que os dados utilizados possuem finalidade exclusivamente didática e que os CPFs apresentados não correspondem a documentos reais, sendo utilizados apenas como identificadores para representar o mesmo indivíduo em diferentes conjuntos de dados.

O conteúdo destaca que os operadores de conjunto trabalham sobre o resultado de consultas independentes, permitindo combinar informações provenientes de diferentes tabelas sem a necessidade de estabelecer relacionamentos por meio de chaves estrangeiras ou operações de junção. Para isso, é necessário que as consultas retornem estruturas compatíveis, respeitando a mesma quantidade de colunas e a compatibilidade entre os tipos de dados. Essa característica diferencia os operadores de conjunto das operações JOIN, pois, enquanto as junções relacionam registros horizontalmente por meio de colunas comuns, os operadores de conjunto combinam verticalmente os resultados produzidos por consultas distintas.

Além da criação das tabelas, o documento apresenta imagens contendo o conteúdo das tabelas FUNCIONARIO, ALUNO e CLIENTE após a inserção dos registros. Esses exemplos evidenciam que alguns indivíduos aparecem em mais de uma tabela, possibilitando a aplicação prática dos operadores UNION, INTERSECT e EXCEPT para identificar registros compartilhados ou exclusivos entre diferentes conjuntos de dados. O uso do CPF como identificador comum permite representar situações típicas encontradas em ambientes corporativos, como integração de sistemas, consolidação de cadastros e cruzamento de informações provenientes de diferentes bases de dados.

De forma geral, o material estabelece os fundamentos necessários para o estudo dos operadores de conjunto no PostgreSQL, preparando o ambiente de dados e apresentando a estrutura que será utilizada nos exemplos práticos. Ao diferenciar claramente os operadores de conjunto das operações de junção, o conteúdo evidencia uma importante categoria de consultas SQL voltadas à integração lógica de resultados, ampliando significativamente as possibilidades de recuperação e análise de informações em bancos de dados relacionais.

# Conclusão

O estudo dos operadores de conjunto representa uma etapa importante no aprofundamento da linguagem SQL, pois demonstra como resultados provenientes de diferentes consultas podem ser combinados, comparados e diferenciados de maneira organizada e eficiente. Ao introduzir os operadores UNION, INTERSECT e EXCEPT, o material amplia significativamente as possibilidades de recuperação de informações em bancos de dados relacionais, oferecendo alternativas que vão além das tradicionais operações de junção entre tabelas.

Ao longo do conteúdo, observa-se que os operadores de conjunto exigem compatibilidade estrutural entre as consultas participantes, reforçando a importância do correto planejamento das instruções SELECT utilizadas em cada operação. Essa exigência garante que os resultados possam ser combinados adequadamente, preservando a consistência dos dados e permitindo que informações provenientes de diferentes tabelas ou sistemas sejam integradas em um único conjunto de resultados. Essa característica torna esses operadores extremamente úteis em processos de consolidação de dados, integração de sistemas, migração de informações e geração de relatórios corporativos.

Outro aspecto relevante apresentado no documento é a utilização de tabelas pertencentes a diferentes domínios de aplicação, como funcionários, alunos e clientes. Essa abordagem demonstra que operadores de conjunto não dependem da existência de relacionamentos definidos por chaves estrangeiras, sendo capazes de integrar informações apenas com base na compatibilidade estrutural das consultas. A utilização do CPF como identificador comum ilustra situações frequentes em organizações que necessitam consolidar cadastros provenientes de diferentes sistemas ou departamentos, permitindo identificar registros comuns ou exclusivos entre múltiplas bases de dados.

Sob a perspectiva profissional, dominar os operadores UNION, INTERSECT e EXCEPT constitui uma competência essencial para desenvolvedores, administradores de banco de dados, engenheiros de dados, analistas de dados e especialistas em Business Intelligence. Esses recursos são amplamente utilizados em projetos de integração de dados, auditorias, processos de ETL, consolidação de informações e construção de consultas analíticas que envolvem múltiplas fontes de dados. Seu uso adequado contribui para consultas mais elegantes, reutilizáveis e eficientes.

Em síntese, o material demonstra que os operadores de conjunto representam um recurso fundamental da linguagem SQL para manipulação e comparação de conjuntos de dados. Ao possibilitar a união, interseção e diferenciação de resultados provenientes de consultas independentes, esses operadores ampliam a capacidade analítica dos bancos de dados relacionais e oferecem soluções robustas para integração de informações em ambientes corporativos, sistemas distribuídos e aplicações modernas orientadas por dados.
