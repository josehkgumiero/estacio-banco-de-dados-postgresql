# Sobre o Projeto

Este repositório reúne todo o conteúdo prático desenvolvido durante a disciplina **Banco de Dados PostgreSQL** da Estácio.

O objetivo do projeto é apresentar, de forma organizada, a evolução do aprendizado da linguagem SQL utilizando PostgreSQL, abordando desde comandos fundamentais até consultas complexas utilizadas em ambientes corporativos.

Todo o conteúdo foi implementado utilizando SQL padrão compatível com PostgreSQL, priorizando boas práticas de desenvolvimento, legibilidade das consultas e organização dos scripts.

Além dos exemplos propostos na disciplina, o repositório também contém projetos práticos desenvolvidos para consolidar os conceitos apresentados durante as aulas.
