# Comandos SQL para Criação de de Banco de Dados
O projeto está disponível em: [Comandos SQL para Criação de de Banco de Dados](./Creation_Database_SQL_Commands.docx)
# Resumo
Este projeto apresenta um estudo sobre os principais comandos SQL utilizados para a criação de bancos de dados e tabelas no PostgreSQL, abordando conceitos fundamentais da linguagem SQL e os recursos disponibilizados pelo SGBD para estruturar ambientes de armazenamento de dados de forma organizada, segura e eficiente. Inicialmente, o documento contextualiza a importância da SQL como linguagem padrão para bancos de dados relacionais, destacando sua origem na IBM durante a década de 1970 e sua posterior padronização pelo ANSI, processo que permitiu reduzir problemas de compatibilidade entre diferentes Sistemas Gerenciadores de Banco de Dados (SGBDs). Além da padronização, o material ressalta que diversos produtos implementam extensões próprias da linguagem SQL para ampliar funcionalidades e facilitar o desenvolvimento de aplicações.

O conteúdo descreve, em seguida, os procedimentos necessários para acessar o PostgreSQL por meio do pgAdmin 4, apresentando a utilização da ferramenta Query Tool para execução de comandos SQL diretamente no servidor. A partir desse ambiente, é demonstrado o processo de criação de um banco de dados utilizando o comando CREATE DATABASE, bem como sua remoção através do comando DROP DATABASE. O documento também introduz o conceito de schema, explicando que todo banco de dados criado no PostgreSQL possui, por padrão, o schema public, responsável por armazenar as tabelas quando nenhum schema específico é informado. Além disso, apresenta a utilização do comando CREATE SCHEMA para organizar objetos em diferentes estruturas lógicas dentro do banco de dados.

Outro tema amplamente abordado é a criação de tabelas utilizando o comando CREATE TABLE. O documento explica detalhadamente a sintaxe desse comando, apresentando seus principais componentes, como definição das colunas, escolha dos tipos de dados, declaração de restrições, criação de chaves primárias (PRIMARY KEY), chaves estrangeiras (FOREIGN KEY) e outras restrições de integridade (CONSTRAINT). Também são apresentados diversos tipos de dados disponíveis no PostgreSQL, incluindo tipos inteiros, numéricos, monetários, datas, horários e cadeias de caracteres de tamanho fixo ou variável, permitindo compreender como selecionar o tipo mais adequado para cada informação armazenada.

Como aplicação prática, o material apresenta um modelo relacional composto pelas tabelas NIVEL e CURSO, demonstrando a implementação do relacionamento entre elas por meio de uma chave estrangeira. O exemplo evidencia a utilização conjunta dos conceitos apresentados anteriormente, como definição de tipos de dados, aplicação de restrições e criação de relacionamentos entre tabelas. O documento também destaca que, em projetos reais, a quantidade de tabelas pode ser significativamente maior, tornando indispensável o uso de ferramentas de modelagem e administração, como DBeaver, Vertabelo, SQL Power Architect, Toad for SQL e Erwin, capazes de automatizar a geração de scripts DDL. Por fim, o conteúdo apresenta uma visão interna do PostgreSQL, explicando que o sistema mantém informações administrativas em um banco de dados especial denominado catálogo, cujas tabelas possuem o prefixo PG_, exemplificando a utilização da tabela PG_DATABASE para consulta dos bancos de dados existentes no servidor.
# Conclsuão
O conteúdo apresentado fornece uma base sólida para compreender os principais conceitos envolvidos na criação de bancos de dados e tabelas utilizando a linguagem SQL no PostgreSQL. Ao abordar desde o contexto histórico da linguagem SQL até a implementação prática de bancos de dados relacionais, o material demonstra como a padronização promovida pelo ANSI contribuiu para tornar a SQL a principal linguagem utilizada pelos Sistemas Gerenciadores de Banco de Dados modernos, mantendo ao mesmo tempo espaço para extensões específicas implementadas por diferentes fornecedores.

O estudo dos comandos CREATE DATABASE, CREATE SCHEMA e CREATE TABLE evidencia a importância da correta organização estrutural dos bancos de dados, permitindo criar ambientes bem definidos, organizados e preparados para armazenar informações de forma consistente. Da mesma forma, a compreensão da utilização de schemas, tipos de dados, restrições de integridade, chaves primárias e chaves estrangeiras demonstra que a modelagem adequada constitui um dos fatores mais importantes para garantir a qualidade, a consistência e a confiabilidade das informações armazenadas em aplicações baseadas em bancos de dados relacionais.

Outro aspecto relevante apresentado pelo documento é a aproximação entre teoria e prática por meio da construção das tabelas NIVEL e CURSO, permitindo visualizar como os conceitos de modelagem relacional são implementados utilizando comandos SQL. Além disso, a apresentação de ferramentas de administração e modelagem demonstra que, embora seja essencial compreender os comandos DDL, o desenvolvimento de projetos reais normalmente conta com soluções que automatizam parte significativa da criação da estrutura do banco de dados e da geração dos scripts SQL, aumentando a produtividade e reduzindo a possibilidade de erros durante o desenvolvimento.

Por fim, o material amplia a compreensão sobre o funcionamento interno do PostgreSQL ao apresentar a existência do catálogo do sistema, responsável pelo armazenamento das informações administrativas dos bancos de dados existentes no servidor. Esse conhecimento contribui para uma visão mais completa do funcionamento do SGBD e reforça a importância de compreender tanto os aspectos conceituais quanto os recursos práticos disponibilizados pelo PostgreSQL. Em conjunto, o conteúdo oferece uma introdução consistente aos comandos SQL voltados para a criação de bancos de dados e tabelas, estabelecendo uma base fundamental para estudos posteriores sobre manipulação de dados, consultas, modelagem relacional e administração de bancos de dados.
