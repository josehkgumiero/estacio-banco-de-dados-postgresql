# Consultas usando a cláusula WHERE
O projeto está disponível em: [Consultas usando a cláusula WHERE](./Queries_WHERE.docx)

# Resumo

O documento apresenta um estudo aprofundado sobre a utilização da cláusula WHERE no PostgreSQL, destacando sua importância como principal mecanismo de filtragem de dados na linguagem SQL. Inicialmente, o material explica que, embora o comando SELECT seja responsável pela recuperação das informações armazenadas em tabelas, é a cláusula WHERE que permite restringir os resultados da consulta, retornando apenas os registros que atendem a critérios específicos definidos pelo usuário. Essa capacidade de selecionar apenas os dados relevantes torna as consultas mais eficientes, reduz o volume de informações processadas e facilita a obtenção de resultados alinhados às necessidades de aplicações, relatórios e análises de dados. O documento enfatiza que o domínio das técnicas de filtragem é indispensável para profissionais que trabalham com bancos de dados relacionais, uma vez que praticamente todas as consultas corporativas utilizam algum tipo de condição para limitar os registros retornados.

Para demonstrar a aplicação prática da cláusula WHERE, o material utiliza uma tabela denominada ALUNO, composta pelos atributos CODIGOALUNO, NOME, SEXO, DTNASCIMENTO e EMAIL. Inicialmente, é apresentado o script completo para criação da tabela utilizando o comando CREATE TABLE, seguido da inserção de registros por meio do comando INSERT INTO, permitindo que o estudante construa uma base de dados funcional para acompanhar todos os exemplos apresentados ao longo do documento. Essa abordagem prática facilita a compreensão dos conceitos e incentiva a execução das consultas diretamente no PostgreSQL, proporcionando maior familiaridade com o ambiente de desenvolvimento e com o comportamento das instruções SQL.

Na sequência, o documento apresenta a sintaxe geral do comando SELECT utilizando conjuntamente as cláusulas FROM, WHERE e ORDER BY. É explicado que o SELECT define quais colunas serão exibidas no resultado da consulta, o FROM indica a tabela que será utilizada como fonte dos dados, o WHERE estabelece as condições responsáveis pela filtragem dos registros e o ORDER BY determina a forma como os resultados serão organizados, permitindo especificar ordenação crescente ou decrescente, além do posicionamento dos valores nulos (NULLS FIRST e NULLS LAST). O material também relaciona a cláusula WHERE ao conceito de restrição (seleção) da Álgebra Relacional, evidenciando que essa operação corresponde à seleção de subconjuntos de registros que atendem a determinadas condições lógicas, constituindo um dos fundamentos teóricos dos bancos de dados relacionais.

Outro aspecto importante abordado refere-se aos operadores relacionais e operadores lógicos utilizados na construção das condições da cláusula WHERE. O documento apresenta operadores de comparação como menor que (<), menor ou igual (<=), maior que (>), maior ou igual (>=), igual (=) e diferente (<> ou !=), explicando que eles permitem comparar valores numéricos, textuais e temporais durante a execução das consultas. Além dos operadores relacionais, são apresentados os operadores lógicos AND, OR e NOT, responsáveis por combinar ou inverter condições, possibilitando a construção de expressões simples ou compostas capazes de representar diferentes regras de negócio. O domínio desses operadores amplia significativamente a capacidade de elaboração de consultas SQL, permitindo selecionar dados com elevado grau de precisão conforme critérios definidos pelo usuário.

Na parte prática, o documento demonstra consultas utilizando a cláusula WHERE para filtrar registros da tabela ALUNO. No primeiro exemplo, são recuperados apenas o nome e a data de nascimento dos alunos do sexo feminino por meio da condição SEXO = 'F'. Em seguida, é apresentada uma consulta mais elaborada que combina o operador lógico AND com a função EXTRACT, retornando somente as alunas que fazem aniversário no mês de novembro. Esse exemplo evidencia a possibilidade de integrar funções SQL com operadores relacionais e lógicos para construir filtros mais sofisticados, permitindo atender requisitos específicos de consulta sem necessidade de processamento adicional pela aplicação.

Ao longo do documento, observa-se que a cláusula WHERE constitui um dos recursos mais importantes da linguagem SQL, sendo utilizada em praticamente todas as consultas realizadas em bancos de dados relacionais. A capacidade de combinar operadores de comparação, operadores lógicos e funções SQL permite construir consultas flexíveis, eficientes e adaptadas às necessidades de diferentes contextos organizacionais. Dessa forma, o material estabelece uma base sólida para o estudo de técnicas mais avançadas de filtragem, consultas complexas e otimização de desempenho em bancos de dados PostgreSQL.

# Conclusão

O estudo da cláusula WHERE evidencia sua importância como um dos principais mecanismos de filtragem de dados da linguagem SQL, permitindo recuperar apenas os registros que atendem às condições definidas pelo usuário. Ao restringir o conjunto de dados retornado pelas consultas, essa cláusula torna o processamento mais eficiente, reduz a quantidade de informações exibidas e possibilita a obtenção de resultados específicos para diferentes necessidades de negócio. Essa característica faz da cláusula WHERE um recurso indispensável para o desenvolvimento de aplicações, elaboração de relatórios, construção de dashboards e realização de análises de dados em bancos de dados relacionais.

O documento também demonstra que a eficiência das consultas depende da correta utilização dos operadores relacionais e operadores lógicos. A possibilidade de comparar valores por meio de operadores como igualdade, desigualdade, maior ou menor, bem como combinar diferentes critérios utilizando AND, OR e NOT, amplia significativamente a flexibilidade da linguagem SQL. Além disso, a integração da cláusula WHERE com funções como EXTRACT permite criar filtros baseados em componentes específicos de datas, possibilitando a implementação de regras de negócio mais sofisticadas diretamente nas consultas ao banco de dados. Essa capacidade reduz a necessidade de processamento adicional pelas aplicações e torna as consultas mais completas e eficientes.

Outro aspecto relevante apresentado pelo material é a integração entre as cláusulas SELECT, FROM, WHERE e ORDER BY, evidenciando que uma consulta SQL eficiente resulta da combinação adequada desses elementos. Enquanto o comando SELECT define quais informações serão retornadas, o FROM especifica a origem dos dados, o WHERE determina quais registros satisfazem os critérios estabelecidos e o ORDER BY organiza os resultados conforme a necessidade do usuário. Essa estrutura representa o padrão utilizado na grande maioria das consultas desenvolvidas em ambientes corporativos, tornando seu domínio essencial para profissionais das áreas de desenvolvimento de software, administração de bancos de dados, Engenharia de Dados, Ciência de Dados e Business Intelligence.

Em síntese, o documento estabelece uma base sólida para o aprendizado das técnicas de filtragem no PostgreSQL, demonstrando que a cláusula WHERE constitui um dos pilares da linguagem SQL. A compreensão de sua sintaxe, dos operadores relacionais, dos operadores lógicos e da integração com funções SQL prepara o estudante para desenvolver consultas cada vez mais sofisticadas, envolvendo múltiplas condições, subconsultas, junções entre tabelas e otimização de desempenho. O domínio desses conceitos permite construir soluções mais eficientes, recuperar informações com maior precisão e desenvolver aplicações capazes de explorar todo o potencial dos bancos de dados relacionais em ambientes corporativos modernos.
