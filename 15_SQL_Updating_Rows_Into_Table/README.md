# SQL para Atualização de Linhas em Tabela
O projeto está disponível em: [SQL para Atualização de Linhas em Tabela](./SQL_Updating_Rows_Into_Table.docx)

# Resumo

Este material apresenta os principais conceitos relacionados à atualização de registros em tabelas utilizando o comando UPDATE da linguagem SQL no PostgreSQL. Inicialmente, o documento explica que a atualização de dados é uma das operações fundamentais da Linguagem de Manipulação de Dados (DML – Data Manipulation Language), permitindo modificar informações já armazenadas no banco de dados de forma controlada e precisa. O conteúdo destaca que o PostgreSQL oferece mecanismos capazes de realizar alterações seletivas em registros específicos, preservando a integridade das informações e garantindo que os dados reflitam corretamente as mudanças ocorridas durante o funcionamento das aplicações. Também é ressaltado que as atualizações podem utilizar condições de seleção e outros recursos avançados disponibilizados pelo SGBD, tornando esse processo seguro e eficiente.

Na sequência, o documento apresenta a sintaxe básica do comando UPDATE, explicando detalhadamente seus principais componentes. São descritos o nome da tabela que será modificada, a cláusula SET, utilizada para definir os novos valores das colunas, e a cláusula WHERE, responsável por selecionar quais registros deverão ser atualizados. O material enfatiza que a utilização da cláusula WHERE é essencial para restringir a atualização apenas aos registros desejados, evitando alterações acidentais em toda a tabela. Para ilustrar esse funcionamento, são apresentados exemplos práticos de atualização da carga horária da disciplina Redes de Computadores, demonstrando diferentes formas de identificar o registro a ser modificado, seja por meio da chave primária ou pelo nome da disciplina.

Além das atualizações individuais, o conteúdo demonstra que o comando UPDATE também pode ser utilizado para alterar simultaneamente um conjunto de registros. Como exemplo, é apresentada uma operação que aumenta em 20% a carga horária de todas as disciplinas cadastradas no banco de dados utilizando uma expressão matemática diretamente na cláusula SET, evidenciando que o PostgreSQL permite realizar cálculos e atualizações em massa de forma simples e eficiente. Esse exemplo mostra que o comando UPDATE pode ser empregado tanto para modificações pontuais quanto para alterações abrangentes envolvendo todos os registros de uma tabela.

Por fim, o documento aborda um tema de grande importância: a atualização de colunas que exercem o papel de chave primária. Inicialmente, é demonstrado um caso em que a alteração da chave primária de um curso é realizada com sucesso, pois não existem registros relacionados em outras tabelas. Em seguida, é apresentado um cenário em que a tentativa de alterar uma chave primária falha devido à existência de registros dependentes na tabela CURSODISCIPLINA, protegidos por uma chave estrangeira. Para solucionar esse problema, o material explica como utilizar o comando ALTER TABLE para remover e recriar a restrição de chave estrangeira com a opção ON UPDATE CASCADE, permitindo que futuras alterações na chave primária sejam propagadas automaticamente para todas as tabelas relacionadas, preservando a integridade referencial do banco de dados.

# Conclusão

O conteúdo apresentado demonstra que o comando UPDATE desempenha um papel fundamental na manutenção das informações armazenadas em bancos de dados relacionais, permitindo modificar registros existentes de maneira segura, precisa e controlada. A correta utilização desse comando possibilita manter os dados atualizados conforme as necessidades das aplicações, sendo uma das operações mais importantes da Linguagem de Manipulação de Dados (DML). O material também evidencia que a utilização adequada da cláusula WHERE é essencial para limitar o alcance das alterações, evitando modificações indesejadas em registros que não deveriam ser atualizados.

Outro aspecto relevante abordado pelo documento é a flexibilidade do comando UPDATE, que permite tanto alterações individuais quanto atualizações em massa utilizando expressões matemáticas e operações sobre os valores já armazenados nas tabelas. Essa característica amplia significativamente as possibilidades de manipulação dos dados, permitindo realizar ajustes globais de forma simples, eficiente e com poucas instruções SQL. Dessa maneira, o PostgreSQL oferece recursos capazes de atender desde pequenas correções até modificações abrangentes em grandes volumes de registros.

O material também evidencia a importância da integridade referencial durante operações de atualização envolvendo chaves primárias. Ao impedir automaticamente alterações que poderiam comprometer os relacionamentos entre tabelas, o PostgreSQL protege a consistência dos dados e evita a criação de registros órfãos ou referências inválidas. A utilização da opção ON UPDATE CASCADE demonstra como o SGBD pode automatizar a propagação dessas alterações para as tabelas dependentes, preservando os relacionamentos existentes e reduzindo a necessidade de atualizações manuais em múltiplas tabelas.

Em conjunto, os conceitos apresentados fornecem uma base sólida para compreender o funcionamento das operações de atualização no PostgreSQL, demonstrando tanto a sintaxe do comando UPDATE quanto os mecanismos utilizados pelo sistema para preservar a integridade dos dados durante modificações em tabelas relacionadas. O domínio desses recursos é essencial para desenvolvedores e administradores de banco de dados, permitindo realizar alterações de forma segura, consistente e alinhada às boas práticas de modelagem e gerenciamento de bancos de dados relacionais.
