# SQL para Atualização de Linhas em Tabela
O projeto está disponível em: [SQL para Atualização de Linhas em Tabela](./SQL_Inserting_Rows_Into_Table.docx)
# Resumo
Este material apresenta os principais conceitos relacionados à inserção de registros em tabelas utilizando a linguagem SQL no PostgreSQL, destacando a importância do comando INSERT para a população de dados em bancos de dados relacionais. Inicialmente, o documento explica que a inserção de registros é uma das operações fundamentais da Linguagem de Manipulação de Dados (DML – Data Manipulation Language), responsável por permitir a criação de novos registros de maneira organizada, consistente e segura. O conteúdo também contextualiza essas operações dentro do conceito de CRUD (Create, Read, Update e Delete), associando cada operação aos respectivos comandos SQL (INSERT, SELECT, UPDATE e DELETE) e demonstrando que a manipulação de dados constitui uma das atividades mais frequentes no desenvolvimento e na administração de bancos de dados relacionais.

Na sequência, o documento apresenta um modelo relacional composto pelas tabelas CURSO, DISCIPLINA e CURSODISCIPLINA, utilizado como base para todos os exemplos práticos. O material explica que a tabela CURSODISCIPLINA representa a associação entre cursos e disciplinas por meio de chaves estrangeiras, constituindo um exemplo clássico de relacionamento muitos-para-muitos em bancos de dados relacionais. A partir desse modelo, são apresentados scripts de criação das tabelas e exemplos de inserção de registros, permitindo compreender como a estrutura do banco de dados influencia diretamente a forma como os dados são armazenados e relacionados.

O conteúdo descreve detalhadamente a sintaxe do comando INSERT INTO, explicando que a instrução deve informar a tabela que receberá os dados, as colunas que serão preenchidas e os respectivos valores a serem inseridos. Também é destacado que cada valor informado deve ser compatível com o tipo de dado definido para sua coluna correspondente, respeitando os domínios estabelecidos durante a criação da tabela. Para ilustrar esse funcionamento, o documento apresenta diversos exemplos de inserção de cursos, disciplinas e registros de associação entre essas entidades, demonstrando como diferentes tipos de dados, como números inteiros, textos e datas, devem ser informados corretamente para que a operação seja executada com sucesso.

Por fim, o material enfatiza o papel do PostgreSQL na garantia da integridade dos dados durante as operações de inserção. São apresentados exemplos em que o SGBD impede automaticamente a inclusão de registros que violam restrições de integridade, como a tentativa de inserir uma chave estrangeira inexistente na tabela de relacionamento, a duplicação de valores de chave primária e a inserção de valores nulos em colunas obrigatórias. Esses exemplos demonstram que o PostgreSQL realiza validações automáticas para preservar a consistência do banco de dados, impedindo operações que possam gerar registros inconsistentes ou comprometer os relacionamentos existentes entre as tabelas.
# Conclusão

O conteúdo apresentado evidencia que a inserção de registros constitui uma das operações mais importantes da manipulação de dados em bancos de dados relacionais, sendo realizada por meio do comando INSERT, integrante da Linguagem de Manipulação de Dados (DML). A correta utilização desse comando permite alimentar as tabelas com informações consistentes e organizadas, tornando possível o funcionamento das aplicações que dependem do armazenamento estruturado de dados. Além disso, a contextualização das operações de inserção dentro do modelo CRUD reforça a importância do domínio das operações básicas de criação, consulta, atualização e remoção de registros para qualquer profissional que trabalhe com bancos de dados.

O estudo do modelo composto pelas tabelas CURSO, DISCIPLINA e CURSODISCIPLINA demonstra como os relacionamentos entre entidades influenciam diretamente as operações de inserção de dados. A existência de chaves primárias e chaves estrangeiras estabelece regras que garantem a integridade referencial do banco de dados, assegurando que somente registros válidos possam ser armazenados. Dessa forma, o material evidencia que a inserção de dados não depende apenas da sintaxe correta do comando SQL, mas também do respeito às restrições definidas durante a modelagem do banco de dados.

Outro aspecto de grande relevância abordado pelo documento é o mecanismo de validação automática implementado pelo PostgreSQL. Ao impedir a inserção de chaves estrangeiras inexistentes, valores duplicados em chaves primárias e registros com valores nulos em campos obrigatórios, o sistema garante que os dados armazenados permaneçam íntegros durante todo o ciclo de vida da aplicação. Esses mecanismos reduzem significativamente a possibilidade de inconsistências e reforçam a confiabilidade do banco de dados como repositório central das informações utilizadas pelos sistemas.

Em conjunto, os conceitos apresentados oferecem uma base sólida para compreender o funcionamento das operações de inserção de dados no PostgreSQL, demonstrando a importância da linguagem SQL, das restrições de integridade e do correto relacionamento entre tabelas. O domínio desses fundamentos representa um passo essencial para o desenvolvimento de aplicações baseadas em bancos de dados relacionais, permitindo realizar operações de manipulação de dados de forma segura, consistente e alinhada às boas práticas de modelagem e administração de bancos de dados.
