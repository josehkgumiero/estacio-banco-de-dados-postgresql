# Projeto consultas com o comando SELECT e a cláusula WHERE
O projeto está disponível em: [Projeto consultas com o comando SELECT e a cláusula WHERE](./Project_Queries_SELECT_WHERE.docx)

# Resumo

O documento apresenta um projeto prático de consultas SQL utilizando o comando SELECT em conjunto com a cláusula WHERE, consolidando os principais conceitos estudados sobre recuperação, filtragem e ordenação de dados no PostgreSQL. O objetivo do material é proporcionar uma aplicação integrada dos recursos da linguagem SQL por meio de um banco de dados corporativo composto pelas tabelas EMPREGADO, CLIENTE, DEPARTAMENTO e REGIÃO, permitindo que o estudante execute consultas semelhantes às encontradas em ambientes empresariais. Inicialmente, o documento apresenta o modelo lógico do banco de dados e um roteiro de atividades práticas que contempla diferentes técnicas de filtragem, incluindo comparações simples, múltiplas condições, operadores IN, BETWEEN, LIKE, IS NULL e ordenação dos resultados por meio da cláusula ORDER BY. Essa abordagem prática demonstra como diversos recursos da linguagem SQL podem ser utilizados de forma integrada para recuperar informações específicas conforme diferentes regras de negócio.

Na sequência, o documento apresenta um arquivo SQL contendo exemplos comentados de consultas desenvolvidas sobre o banco de dados da empresa. O primeiro conjunto de exemplos aborda filtros simples utilizando operadores relacionais, como a recuperação de empregados cujo identificador seja maior que determinado valor e a localização do identificador de um cliente específico por meio da comparação direta do nome. Esses exemplos demonstram a utilização básica da cláusula WHERE para restringir os registros retornados, evidenciando que a filtragem constitui um dos recursos mais importantes da linguagem SQL para recuperar apenas as informações relevantes em um banco de dados relacional.

O documento também explora consultas envolvendo múltiplas condições, utilizando os operadores lógicos AND e OR para combinar diferentes critérios de seleção. Como exemplo, são apresentadas consultas que recuperam empregados pertencentes a determinado departamento e com salário superior a um valor específico, além de consultas que retornam profissionais ocupando cargos distintos. Esses exemplos demonstram como operadores lógicos permitem representar regras de negócio mais complexas diretamente na linguagem SQL, tornando possível construir filtros capazes de atender diferentes necessidades organizacionais sem a necessidade de processamento adicional pelas aplicações.

Outro conjunto de exemplos aborda a utilização dos operadores IN e BETWEEN, responsáveis por simplificar consultas baseadas em listas de valores e intervalos. O operador IN é utilizado para recuperar empregados pertencentes a determinados departamentos e clientes cujos nomes estejam presentes em uma lista previamente definida, enquanto o operador BETWEEN é aplicado para selecionar empregados cujo salário ou data de admissão estejam compreendidos entre limites específicos. O documento evidencia que esses operadores tornam as consultas mais legíveis e reduzem a necessidade de múltiplas comparações utilizando operadores relacionais convencionais, contribuindo para a construção de códigos SQL mais organizados e de fácil manutenção.

Na sequência, o material apresenta exemplos envolvendo o operador LIKE, utilizado para pesquisas baseadas em padrões textuais. São demonstradas consultas que recuperam empregados cujo primeiro nome inicia com determinada letra, cujo sobrenome termina com uma sequência específica de caracteres, contém determinada expressão em qualquer posição ou apresenta quantidade fixa de caracteres. Em seguida, são apresentados exemplos utilizando o operador IS NULL, responsável por identificar registros que ainda não possuem valores cadastrados, como clientes sem vendedor associado e empregados que não possuem gerente definido. Esses exemplos demonstram que a linguagem SQL oferece recursos específicos tanto para manipulação de informações textuais quanto para o tratamento adequado de valores nulos em bancos de dados relacionais.

Por fim, o documento aborda a utilização da cláusula ORDER BY para organizar os resultados das consultas. São apresentados exemplos de ordenação crescente pelo primeiro nome dos empregados, ordenação decrescente por salário, classificação combinando departamento e salário e organização cronológica pela data de admissão. Esses exemplos demonstram que a ordenação pode utilizar um ou múltiplos critérios, permitindo apresentar os dados de maneira estruturada e adequada para relatórios, sistemas corporativos e análises gerenciais. Ao integrar todos esses recursos em um único projeto, o documento consolida os principais conceitos estudados sobre consultas SQL, proporcionando uma visão prática e abrangente da recuperação de dados no PostgreSQL e preparando o estudante para o desenvolvimento de consultas mais sofisticadas em ambientes corporativos.
# Conclusão

O projeto demonstra de forma prática como os principais recursos de consulta da linguagem SQL podem ser aplicados de maneira integrada em um banco de dados relacional utilizando o PostgreSQL. Ao reunir exemplos envolvendo operadores relacionais, operadores lógicos, filtros por listas, intervalos, padrões textuais, tratamento de valores nulos e ordenação de resultados, o documento evidencia que a construção de consultas eficientes depende da combinação adequada desses recursos para atender às diferentes necessidades de recuperação de informações existentes em sistemas corporativos. Essa abordagem proporciona ao estudante uma visão mais completa do funcionamento da linguagem SQL e de sua aplicação em cenários reais de desenvolvimento de software e gerenciamento de bancos de dados.

Outro aspecto relevante do material é a utilização de um banco de dados empresarial contendo múltiplas entidades relacionadas, aproximando o processo de aprendizagem das situações encontradas em ambientes profissionais. As consultas apresentadas demonstram como recuperar informações específicas sobre empregados, clientes, departamentos e regiões, utilizando critérios de seleção cada vez mais sofisticados. Essa evolução progressiva permite compreender como consultas simples podem ser transformadas em instruções capazes de representar regras de negócio complexas, contribuindo para o desenvolvimento de aplicações mais robustas e para a produção de relatórios gerenciais confiáveis.

O documento também evidencia a importância das boas práticas na elaboração de consultas SQL. A utilização de operadores como IN, BETWEEN, LIKE, IS NULL e da cláusula ORDER BY torna o código mais organizado, legível e de fácil manutenção, reduzindo a complexidade das expressões condicionais e facilitando futuras alterações. Além disso, a presença de comentários explicativos ao longo do arquivo SQL contribui para a documentação do código e para a compreensão das consultas por outros desenvolvedores, característica fundamental em projetos colaborativos e ambientes corporativos de desenvolvimento de software.

Em síntese, o projeto consolida os principais conceitos relacionados à recuperação e filtragem de dados estudados ao longo do módulo, demonstrando que a linguagem SQL oferece um conjunto amplo de recursos para selecionar, restringir, organizar e apresentar informações de maneira eficiente. O domínio dessas técnicas constitui uma competência essencial para profissionais das áreas de Desenvolvimento de Software, Administração de Bancos de Dados, Engenharia de Dados, Ciência de Dados e Business Intelligence, servindo como fundamento para o estudo de tópicos mais avançados, como junções (JOIN), agrupamentos (GROUP BY), funções analíticas, subconsultas complexas, otimização de consultas e desenvolvimento de soluções analíticas baseadas em bancos de dados relacionais.
